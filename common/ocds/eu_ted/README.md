# common/ocds/eu_ted

TED XML to OCDS parser. Parses TED notice XML files (both old TED format and
new eForms) into OCDS (Open Contracting Data Standard) release objects.

Partly ported from [TEDective](https://git.fsfe.org/TEDective/etl), adapted for
use with [investigraph](https://docs.investigraph.dev) and transform to [FollowTheMoney data format](https://followthemoney.tech).
